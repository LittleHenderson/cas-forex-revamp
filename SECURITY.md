# Security Model: Dual-Mode `DEMO` Default + Cryptographically Armed `LIVE` Real-Money Controls

- **Target System**: `CAS Forex Revamp` dual-shield trading architecture (`Hugo's Way MT5`, `LHFX MT5`, and `OANDA`).
- **Default Execution Mode (`DEMO` Fail-Closed)**: Every clean boot, default CLI invocation, and test environment locks to `CAS_FOREX_EXECUTION_MODE=DEMO` (`Hugosway-Demo`, `LHFXSA-Trade` + `ACCOUNT_TRADE_MODE_DEMO`, and `https://api-fxpractice.oanda.com/v3`). Demo runs strictly reject any real-money server or `ACCOUNT_TRADE_MODE_REAL` account with `LiveBrokerEndpointForbiddenError`.
- **Cryptographically Armed `LIVE` Mode**: Opting into `CAS_FOREX_EXECUTION_MODE=LIVE` requires **all** of:
  1. An owner-only (`0o600` POSIX) private HMAC key file at `CAS_FOREX_LIVE_AUTH_KEY_FILE` (`>= 32` random bytes, non-symlink).
  2. An unexpired `HMAC-SHA256`-signed `LiveAuthorizationTicket` (`CAS_FOREX_LIVE_AUTH_TICKET_FILE` / `CAS_FOREX_LIVE_AUTH_TICKET`, max `24h` TTL) binding exact `broker_id`, `account_login`, pinned `server`, and `execution_mode=LIVE`.
  3. Exact dual-confirmation phrase `CAS_FOREX_LIVE_ARM_PHRASE=I_AUTHORIZE_LIVE_REAL_MONEY_TRADING` plus `CasForexMt5Bridge.mq5` `ModeGuard()` verification of `ACCOUNT_TRADE_MODE_REAL` and `live_auth_ticket.json`.
- **Mandatory Runtime & Execution Safety Controls**:
  - **Active Admission Valve (`ForexMetaValveGate`)**: Evaluates every `OPEN`, `ADD`, `REDUCE`, `CLOSE`, and `AMEND_STOP` proposal against an `8 -> 16 (tanh) -> 1 (sigmoid)` neural controller and deterministic hard vetoes, backed by a durable SQLite WAL `PeakEquityStore` enforcing a `10.00%` maximum drawdown cutoff on new risk while preserving `WAIT`, `REDUCE`, and `CLOSE`.
  - **Barbell Capital & Quote-Truth Protection**: Caps per-trade stop-loss risk at `1.00%` of total equity, bounds offshore `LHFX` sleeve exposure, cross-checks MT5 quotes against OANDA/index references, and freezes on ambiguous post-dispatch outcomes (`Mt5OutcomeUnknownError` / `OandaOutcomeUnknownError`) until reconciled.
  - **Spool & State Integrity**: `cas-forex-mt5-spool/2` authenticates MT5 requests and receipts with `HMAC-SHA256`, TTL expiry, and persistent monotonic replay ledgers inside owner-only (`0o700`) `CAS_FOREX_STATE_DIR` alongside single-use `OwnerRecoveryVerifier` unlock tokens and `DurableModelExecutionGate` spend ceilings.
  - **Exchange Off-Ramp Boundary**: `CoinbaseOfframpClient` (`ES256` CDP v3 JWT) and `KrakenOfframpClient` (`HMAC-SHA512`) convert trading sweep reserves strictly to `USD` and settle only to the owner's pre-registered linked US checking ACH account ID (arbitrary external crypto transfers are prohibited).
